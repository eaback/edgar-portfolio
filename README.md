# edgarbacker.dev

Personal portfolio and project showcase — built with Next.js, TypeScript, and Tailwind CSS.

🌐 **Live**: [edgarbacker.dev](https://edgarbacker.dev)

---

## About

Portfolio site for Edgar Backer — fullstack developer based in the Swedish mountains, building EU-first web platforms for Scandinavian businesses.

The site serves as the central hub for project case studies, technical writing, and professional presence. Each project page includes context, tech decisions, architecture overview, and results.

---

## Tech Stack

- **Next.js 15** — App Router, React Server Components
- **TypeScript** — strict mode
- **Tailwind CSS** — utility-first styling
- **next-intl** — internationalization (NL/SV/EN/NO/DE)
- **Deployment** — Hetzner VPS via Coolify
- **Analytics** — Umami (self-hosted, GDPR-compliant)

---

## Features

- Responsive, mobile-first design
- Dark/light mode with system preference detection
- Multilingual (Dutch, Swedish, English, Norwegian, German)
- Project case studies with architecture overviews
- SEO optimized (meta tags, Open Graph, sitemap)
- Zero third-party trackers, EU-hosted analytics
- Accessible: semantic HTML, keyboard navigation

---

## Development

```bash
npm install
npm run dev          # Dev server at localhost:3000
npm run build        # Production build
npm run lint         # ESLint
```
